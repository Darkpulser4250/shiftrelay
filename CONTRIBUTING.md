# Contributing

Start with the README limitations and research plan. Include reproducible fixtures with no copyrighted media, credentials, account identifiers or personal viewing logs. Record device/OS/app versions for compatibility reports. Separate proxy connectivity, TLS inspection, media visibility and effective ad suppression.

Run `python -m unittest discover -s tests -v` after installing requirements.txt and research.txt. Fix false positives with regression tests; do not label unrelated changes “AI-powered”. New host inspection, routing modes, output capture and device-control adapters need explicit documentation of user consent and rollback.

Do not add guessed Netflix/Hulu selectors or pretend that owned-media fixture results prove platform compatibility. External libraries and algorithms need license/source attribution.
